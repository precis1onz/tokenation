# Tokenation

Tokenation collects free LLM API offers and checks every entry against the provider's own pages. Offers are split into two kinds:

**Evergreen free tiers** — standing free quotas with no announced end date, plus new-account trial allowances. Every entry records the free quota, the rate limits, the free model IDs and the sign-up link.

**Limited-time offers** — announced by the provider as free for a limited time, either with a fixed end date or with no published deadline (the entry says so). Offers whose announced deadline has already passed are removed.

Updated 2026-10-19.

# Tokenation（中文）

Tokenation 每日搜集免费 LLM API，并逐条回到厂商官方页面核实。条目分两类：

**常态免费（Evergreen）** —— 官方定价页长期挂着、无公告结束时间的免费额度，含新用户免费额度。每条记录免费额度、频控限制、当前免费的模型 ID 与注册链接。

**限时免费（Limit-time）** —— 官方明示的限时免费 offer，含两类：写明固定截止日的，以及只写「限时」未公布截止日的（会在日期字段注明）。已过公布截止日的条目一律移除。

更新至 2026-10-19。
