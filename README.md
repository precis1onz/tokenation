# Tokenation

Tokenation collects free LLM API offers and checks each one against the provider's own pages. Every entry records the free quota, the rate limits, the model IDs that are currently free, and the sign-up link.

Two lists are published from the same data:

- [cn/ALL.md](cn/ALL.md) - Chinese edition
- [en/ALL.md](en/ALL.md) - English edition
